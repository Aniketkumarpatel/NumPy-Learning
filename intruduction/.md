# NumPy `.shape`

## Introduction

`.shape` ka use NumPy array ke **dimensions**, jaise rows aur columns, check karne ke liye hota hai.

### Example

```python
import numpy as np

arr = np.array([[1, 2, 3],
                [4, 5, 6]])

print(arr.shape)
```

### Output

```text
(2, 3)
```

Here:

* `2` → number of rows
* `3` → number of columns

# Common Aggregation Functions

Aggregation functions ka use array ke numerical data par calculations perform karne ke liye hota hai.

| Function      | Use                |
| ------------- | ------------------ |
| `np.sum()`    | Total sum          |
| `np.mean()`   | Average            |
| `np.median()` | Median             |
| `np.min()`    | Minimum value      |
| `np.max()`    | Maximum value      |
| `np.std()`    | Standard deviation |
| `np.var()`    | Variance           |
| `np.prod()`   | Product            |

### Example

```python
import numpy as np

arr = np.array([10, 20, 30, 40, 50])

print(np.sum(arr))
print(np.mean(arr))
print(np.min(arr))
print(np.max(arr))
```

# Fancy Indexing in NumPy

## Introduction

**Fancy indexing** means selecting specific elements from a NumPy array using a **list or array of indices**.

### Example

```python
import numpy as np

arr = np.array([10, 20, 30, 40, 50])

result = arr[[0, 2, 4]]

print(result)
```

### Output

```text
[10 30 50]
```

Here, indices `0`, `2`, and `4` are used to select specific elements.

# `ravel()` and `flatten()`

Both `ravel()` and `flatten()` are used to convert a multi-dimensional array into a **one-dimensional array**.

## Simple Difference

| Function    | Description                                      |
| ----------- | ------------------------------------------------ |
| `ravel()`   | Usually returns a **view** of the original array |
| `flatten()` | Always returns a **copy** of the original array  |

### Example

```python
import numpy as np

arr = np.array([[1, 2],
                [3, 4]])

print(arr.ravel())
print(arr.flatten())
```

### Output

```text
[1 2 3 4]
[1 2 3 4]
```

# Append in NumPy

## Introduction

`np.append()` is used to **add new elements** to an array.

### Example

```python
import numpy as np

arr = np.array([1, 2, 3])

new_arr = np.append(arr, 4)

print(new_arr)
```

### Output

```text
[1 2 3 4]
```

`np.append()` returns a **new array**; it does not modify the original array directly.

# Yes. These are Advanced NumPy array operations. Here are simple definitions:

1. append.py

np.append() is used to add elements to an existing NumPy array.

2. concate.py

np.concatenate() is used to join two or more NumPy arrays together.

3. delete.py

np.delete() is used to remove specific elements from a NumPy array.

4. delete_2d.py

np.delete() is used with a 2D array to remove specific rows or columns.

5. insert.py

np.insert() is used to insert new elements at a specific index in an array.

6. insert_in_2d.py

np.insert() is used with a 2D array to insert rows or columns at a specific position.

7. splitting.py

np.split() is used to divide an array into multiple smaller arrays.

8. stacking.py

np.stack() is used to combine multiple arrays into a new array along a new axis.

# | Operation   | Function           | Meaning                  |
| ----------- | ------------------ | ------------------------ |
| Append      | `np.append()`      | Add elements             |
| Concatenate | `np.concatenate()` | Join arrays              |
| Delete      | `np.delete()`      | Remove elements          |

| Split       | `np.split()`       | Divide array             |
| Stack       | `np.stack()`       | Combine arrays           |
